    Parts and instruments

    Sounds download the first time a part uses them, then stay in this browser. Without a connection, parts play a plain tone.

    Your sounds

      One recording, played higher or lower for the other notes in its range; notes outside it use the part's instrument. Sounds stay in this browser. Saved files keep only the part's instrument.

      Tuplet

      With notes selected, they become one group. Otherwise the next notes you enter are. Press 9 or ; to turn the last group type on or off.

      Scores in this browser

        Scores are kept only in this browser on this device. Use Save to keep a file you can back up or open elsewhere.

        About Coda

        Coda is a free, open-source music notation editor that runs in your browser. Your scores stay in this browser unless you save them as files.

        Source code and licence (MIT): github.com/riceelijah/coda

        Notation drawn with VexFlow (MIT) and the Bravura font (SIL OFL). Zip support by fflate (MIT). Instrument sounds: the FluidR3_GM sound set by Frank Wen (MIT), as MP3s from gleitz/midi-js-soundfonts (CC BY 3.0), downloaded when first used.

        Keyboard shortcuts

        A–GAdd that note after the selected note, or at the end of the current bar (nearest octave)
        R or 0Add a rest
        7 6 5 4 3 2Whole, half, quarter, eighth, 16th, 32nd (also changes the selected note)
        .Dot (press again for a double dot, again for none)
        + - NSharp, flat, natural
        TTie the selected note to the next
        ↑ ↓Move the selected notes by a step (with Shift or Ctrl/Cmd: an octave)
        ← →Select the previous / next note (with Shift: extend the selection)
        Ctrl/Cmd+C / X / VCopy / cut / paste the selected notes (paste goes after the selection)
        9 or ;Tuplets on/off for the next notes (Notes ▸ Tuplet… picks the kind)
        DeleteDelete the selected notes
        VSwitch between the Selection tool and the Note entry tool
        Ctrl/Cmd+ASelect all notes in this staff
        Right-clickActions for the note or bar under the pointer (also Shift+F10)
        EscClear the selection
        SpacePlay / stop
        Ctrl/Cmd+ZUndo (add Shift to redo)
        Ctrl/Cmd+S / OSave / open
        File ▸ ScoresScores saved in this browser: open, duplicate, delete
        ClickNote entry tool: add a note where you click (between notes inserts); click a note to select it
        Click / dragSelection tool: select a note, or drag across notes; Shift+click extends
        Shift+A–GAdd that note above the selected note (build a chord)
        Shift+clickAdd or remove a chord note on the clicked note
        Notes ▸ Fermata…MarcatoAdd or remove a fermata or articulation on the selected notes (also on right-click)
        File ▸ Print… (Ctrl/Cmd+P)Print the score, or save it as a PDF from the print dialog
        File ▸ ExportPDF (through the print dialog), MusicXML, .mxl, MuseScore, MIDI, WAV or compressed audio
        Score ▸ Parts and instruments…Add, remove, rename and reorder parts, and pick each part's sound
        Score ▸ Parts and instruments… ▸ Concert pitch / B♭ / F…Write a part for a transposing instrument; it still sounds the same
        Score ▸ Parts and instruments… ▸ Your sounds…Use your own recording for a part; saved files keep only the part's instrument
        Layer 1–4 (lower left)Pick which layer you enter and edit in (Notes ▸ Layer); other layers show grey
        Chord buttonClicks add notes to the selected note instead of after it
